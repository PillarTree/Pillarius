# Pillarius Downloads

Download site and release ISOs for the Pillarius desktop environment.

- **Site:** https://pillartree.github.io/Pillarius/
- **Releases:** https://github.com/PillarTree/Pillarius/releases

## Publishing new ISOs

Build with [Pillarius-live](https://github.com/PillarTree/Pillarius-live) (or the
local `Pillarius-live` project), then:

```
./publish.sh
```

This uploads every `*.iso` + `*.iso.sha256` in the build `output/` directory to
GitHub Releases (creating or updating release tags), regenerates `index.html`
from the release list, and pushes the site update.

## Layout

| Path | Purpose |
| --- | --- |
| `index.html` | Downloads page (generated by `update-index.sh`) |
| `publish.sh` | Upload ISOs to Releases, refresh the page |
| `update-index.sh` | Regenerate `index.html` from Releases |
| `.github/workflows/pages.yml` | Deploy this repo to GitHub Pages |
